# Дать пять

Сделал себе и друзьям приложение, чтобы "давать пять" по сети — как жест в Dota2,
только работает вообще всегда, в любой игре, поверх всего. Жмёшь свою горячую
клавишу — все, кто в сети и запустил это же приложение, получают уведомление и
звук. Если кто-то ответил тем же в течение 4 секунд — засчитывается match,
играет хлопок и вылетает большая анимация.

Работает через локальную сеть (в том числе через Radmin VPN), без всяких
серверов — все компьютеры просто шлют друг другу UDP-пакеты напрямую.

## Что нужно для запуска

- Windows (звук и оверлей завязаны на Windows API)
- Либо готовый `.exe` (просто запускаешь), либо Python 3.9+, если хочешь
  запускать из исходников

### Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

Окно консоли можно свернуть, приложение работает в фоне. Хочешь совсем без
чёрного окна консоли — запускай через `pythonw main.py`.

### Собранный .exe

Просто кидаешь `Dota5.exe` + `config.json` в одну папку и запускаешь exe.
Ничего ставить не нужно.

## Как это работает

1. Жмёшь свою горячую клавишу (по умолчанию `Ctrl+Alt+x`).
2. У тебя и у всех остальных в сети сразу проигрывается звук и вылетает
   надпись, кто дал пять.
3. Если кто-то из друзей нажмёт свою клавишу в течение 4 секунд после
   твоей — у всех, кто попал в это окно, играет отдельный звук хлопка и
   выскакивает анимация с именами.
4. Если никто не ответил — у тебя лично играет третий, "грустный" звук.
5. После удачного match твоя клавиша на 60 секунд блокируется — чтобы не
   спамили одним и тем же хлопком без остановки.

Никакого центрального сервера нет — все общаются напрямую по UDP в локальной
сети, каждый компьютер сам решает, было совпадение или нет.

## Настройка — всё в `config.json`

```json
{
  "username": "Rikx",
  "hotkey": "ctrl+alt+x",
  "port": 47990,
  "window_ms": 4000,
  "peers": [],
  "extra_broadcast": [],
  "sound_send": "send.wav",
  "sound_match": "match.wav",
  "sound_no_match": "no_match.wav",
  "animation_seconds": 1.2,
  "font_family": "Segoe UI Emoji",
  "cooldown_seconds": 60,
  "text_color": "#8E0039"
}
```

| Поле | Что делает |
|---|---|
| `username` | Имя, которое видят остальные |
| `hotkey` | Своя комбинация клавиш, например `"ctrl+alt+f"`, `"f9"`, `"shift+g"` |
| `port` | UDP-порт (у всех в сети должен совпадать) |
| `window_ms` | Сколько миллисекунд ждать ответного хлопка, чтобы засчитать мэтч |
| `peers` | IP друзей в сети напрямую, если broadcast не долетает, например `["26.10.20.31"]` |
| `sound_send` / `sound_match` / `sound_no_match` | Свои `.wav`-файлы для трёх разных звуков (см. ниже) |
| `animation_seconds` | Сколько длится большая анимация мэтча |
| `cooldown_seconds` | Сколько секунд клавиша блокируется после удачного мэтча |
| `overlay_width` / `overlay_height` | Размер всплывающего окна с текстом (px) |
| `text_color` | Цвет текста, например `"#ff6b00"` или `"yellow"` |

После любых изменений в `config.json` нужно перезапустить приложение.

## Три звука

- **send** — играет у всех, когда кто-то просто нажал клавишу
- **match** — играет у всех, кто попал в совпадение (настоящий "хлопок")
- **no_match** — играет только у тебя, если на твой хлопок никто не ответил

Если своего звука нет — играет синтезированный звук по умолчанию для каждого
случая, ничего докачивать не надо.

### Как поставить свои звуки

1. Возьми короткие `.wav`-файлы (1-2 секунды).
2. Положи рядом с `.exe` / `main.py`.
3. Впиши имена файлов в `config.json`:
   ```json
   "sound_send": "send.wav",
   "sound_match": "match.wav",
   "sound_no_match": "no_match.wav"
   ```
4. Перезапусти приложение.

Раздавая друзьям, кидай им и `.wav`-файлы тоже — звук хранится локально у
каждого, по сети передаётся только сигнал "кто-то нажал", а не сам файл.

## Сеть / Radmin VPN

Обычно всё работает из коробки — приложение само рассылает сигнал на все
подходящие адреса. Если у кого-то из друзей "пять" не долетает:

1. В Radmin VPN узнай IP друга (правый клик на его имени в списке участников).
2. Впиши этот IP в `peers` в `config.json`:
   ```json
   "peers": ["26.10.20.31", "26.10.20.32"]
   ```
3. Разреши приложению доступ в Брандмауэре Windows (для частных и
   общедоступных сетей) — Windows обычно сама спрашивает при первом запуске.
4. Проверь, что у всех одинаковый `port`.

## Поведение в играх

- Оверлей не перехватывает клики — под ним нормально работает мышь в игре.
- Оверлей не забирает фокус у игры (сделано через `WS_EX_NOACTIVATE`), поэтому
  игра в Borderless / Fullscreen Windowed не должна сворачиваться при
  появлении анимации.
- В настоящем **Exclusive Fullscreen** (не оконном) режиме некоторых игр
  сторонние окна всё равно могут выбивать фокус — если так происходит,
  переключи игру в Borderless / Fullscreen Windowed в настройках видео.
- Если горячая клавиша не срабатывает в игре — тоже попробуй переключить
  игру в оконный режим.

## Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name "Dota5" main.py
```

Готовый файл будет в `dist/Dota5.exe`. После сборки положи рядом с ним
`config.json` (и свои `.wav`, если используешь) — приложение читает их из
своей папки.

Своя иконка:
```bash
pyinstaller --onefile --noconsole --icon=icon.ico --name "Dota5" main.py
```
(нужен файл `icon.ico` рядом с `main.py`)

## Если что-то не работает

Приложение собрано с `--noconsole`, поэтому в обычном режиме окна консоли
не видно. Если что-то падает или ведёт себя не так — рядом с `.exe` создаётся
файл **`error.log`**, там будет точная причина.

Частые случаи:
- **Совсем ничего не происходит при нажатии клавиши** — смотри `error.log`,
  скорее всего где-то исключение при старте.
- **Нет звука** — проверь громкость и микшер Windows для процесса
  `Dota5.exe`, и что путь к `.wav`-файлу в `config.json` указан верно.
- **Друг не получает мои "пять"** — впиши его IP в `peers`, проверь firewall
  и что порт одинаковый у всех.
- **Игра сворачивается** — см. раздел про Exclusive Fullscreen выше.
- **Перезапустите ПК**
